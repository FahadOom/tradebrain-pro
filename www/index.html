Signal history: did the candles follow our A+ calls?
Replays the last 7 days (as far back as the data goes on this timeframe). It lists every A+ signal the app would have given, buys and sells, and what the price did next with the same stop and targets as the plan.
Backtest: does the strategy really work?
Replays past candles, takes every signal with the same stop and targets as the plan, and counts wins and losses. 1-hour or 4-hour charts give the most history.
Strategy lab: can any tweak really work?
Tests 288 variations of the strategy on months of history across all nine markets. It learns on the first 60% and is judged only on the last 40%, which it never saw. Takes a few minutes, so keep the screen on.
Lines: green = support, red = resistance, dashed = supply/demand zones, purple dotted = Fibonacci, thick line = trendline, arrows = liquidity sweeps, blue/orange = EMA 50/200, thin lines = last week's swing highs and lows that run until price breaks them, HH/HL/LH/LL = market-structure labels, blue/red/green lines = entry, stop loss and targets. This is an analysis tool with an untested scoring system (backtester comes next). It is not financial advice and cannot predict the market.
